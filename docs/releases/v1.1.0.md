# Brickpress 1.1.0 — 3D editor and refreshed interface

Test builds for Windows x64, macOS Apple Silicon and Intel, and Linux x64.

- A new 3D board uses the catalog's actual geometry, raised pieces and studs.
  Place, move, select, drag to fill, sample with middle-click, use composition
  presets and tracing guides, and undo changes across Design and 3D.
- Linear perspective is the default. Choose Orthographic in Camera → Projection.
  Right-drag or Alt + arrows to orbit; Hand/Space-drag pans. Rotation keeps
  camera distance and zoom steady, fixing the unwanted auto-fit enlargement.
- The interface follows the system light/dark appearance, with compact controls,
  consistent spacing, clearer menus, visible focus, and responsive drawers.
  Notifications can be dismissed and pause while hovered or focused.
- Existing version-1 projects, presets, paper, inks and 2D PNG/SVG exports remain
  compatible. Camera/projection settings and tracing guides stay out of exports.

All five installers are built from the same source commit. The release includes
`SHA256SUMS.txt`; verify your download using the commands in the
[signing guide](../signing.md). Build and automated test results are linked on the
release page. Native automated checks use isolated test data and queued dialog
outcomes; interactive installation, upgrade and actual native pickers still need
hands-on testing on each OS. WebGL is required for 3D; Design remains available
if the device's webview cannot provide it.

The automated Windows, Apple Silicon and Linux webviews rendered and edited 3D,
including a 2,000-piece board. The hosted Intel Mac returned an already-lost
WebGL context; its tests verified the accessible fallback, preserved artwork,
and return to Design instead. 3D rendering on a physical Intel Mac still needs
hands-on testing. Each platform passed 18 native scenarios; real OS picker and
interactive installer checks remain manual.

Windows builds are unsigned. macOS builds use free ad hoc signing and are not
notarized. These remain prereleases for friend testing; updates are installed
manually. Existing projects and desktop application data are preserved by the
application's normal storage workflows.

Windows: run the setup executable. macOS: mount the matching architecture's
DMG and drag Brickpress to Applications. Linux: make the AppImage executable,
or install the Debian package with `sudo apt install ./Brickpress_*.deb`.
See the [desktop guide](../desktop.md) for prerequisites and security prompts.
